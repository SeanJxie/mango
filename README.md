# trace
A 3D renderer that implements path tracing on the CPU using only the Go standard library.

Features:
- Render preview using SDL.
- Concurrent tile-based rendering.


## Goal
This is a learning project!

I'm reading *Physically Based Rendering (4th ed.)* by Matt Pharr, Greg Humphreys, and Pat Hanrahan.

You can find it here: https://pbrt.org/

## Why Go?
Its readability and automatic garbage collection allow me to focus on the learning, even if it's at the cost of speed (compared to C/C++).
